# Brag Plan: Byakugan

1. App: a native Windows disk analyzer with an NTFS scanner, nested treemap and file/folder cleanup actions.
2. Strongest grounded claim: “See where your space goes.” Allocation is distinct from logical size.
3. Visual hook: a readable, pastel nested treemap on forest/cream chrome, using the Partition mark.
4. Actual UI: location chooser, demo overview, Games drilldown, file selection, recycle confirmation.
5. Duration: exactly 25 seconds, 1920×1080 landscape, 30 fps.
6. Tone: polished; a calm desktop tool with a clear sequence, not a performance advertisement.
7. Audio: low warm music bed from brag, two quiet selection sounds; no narration.
8. Share copy: “Byakugan shows where your disk space goes. Explore a nested map, compare allocated and logical size, and review file or folder cleanup before it happens.”
9. Flow: choose location → inspect large items → review cleanup and cancel safely.

25 = 3 + 5 + 9 + 5 + 3. Persistent small caption labels edited demo captures; the cleanup scene is a disposable fixture and no removal is performed. No user paths, private inventories, or measured scan-speed claims.

## Visual identity

LOOK: background #202620; text #E8EDE4; accent #B7CDB0; Recursive Sans Linear 400/600 from the app; 1920×1080; 96px outer margins; 64px headlines; screenshot stage 1278×852; supplied Partition mark.
BANNED: generic feature cards, speed claims, fake progress, deletion success, drifting titles, redesigned application controls.
